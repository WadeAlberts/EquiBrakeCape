Project: Equi Brake Cape — EBC Brake Store

I am building an online brake parts store using Python and Flask. I am a business analyst, not a developer. Please explain everything simply.

Tech stack: Python, Flask, SQLite, HTML/CSS/JS. No frameworks like React.

GitHub repo: https://github.com/WadeAlberts/EquiBrakeCape.git

Folder structure:



```

EquiBrakeCape/

├── app.py                  ← Main Flask server, all routes and API

├── database.py             ← Creates all 5 database tables

├── import_prices.py        ← Imports EBC pricelist Excel into products table

├── import_catalogue.py     ← Imports vehicle catalogue Excel (~30k rows)

├── products.db             ← SQLite database (local only, not on GitHub)

├── .gitignore              ← Excludes .db and .xlsx files

└── templates/

    ├── index.html          ← Home page with vehicle finder + category browser

    ├── results.html        ← Search results page showing matching parts

    ├── cart.html           ← Shopping cart page

    ├── checkout.html       ← Checkout form (name, email, address)

    └── order_confirmation.html ← Post-order confirmation page

```



Database tables: vehicles, products, vehicle_fitment, orders, order_items
